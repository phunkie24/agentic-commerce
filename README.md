# Agentic Commerce - AI-Powered E-Commerce Platform

An intelligent e-commerce platform powered by AI agents implementing 21 design patterns.

## Quick Start

1. Copy environment file:
```bash
cp .env.example .env
```

2. Edit `.env` with your API keys

3. Start all services:
```bash
docker-compose up -d
```

4. Access the application:
- Frontend: http://localhost:3000
- API Docs: http://localhost:8000/docs
- Grafana: http://localhost:3001

## Features

- Natural language shopping assistant
- Personalized recommendations
- Autonomous inventory management
- Dynamic pricing
- Multi-agent customer service
- Fraud detection

## Architecture

- Frontend: React 18 + TypeScript
- Backend: Python 3.11 + FastAPI + LangChain
- Databases: PostgreSQL, Redis, Pinecone
- Infrastructure: Docker, RabbitMQ
